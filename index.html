Tentang

Bikin kernel, bukan cuma pakainya.

Fokusku kernel Android untuk Redmi Note 12 Pro 4G (sweet2/sweet_k6a) — Linux 4.14, basis LineageOS dan OpenELA, toolchain clang, dengan fitur seperti BPF, KSU, dan pengaturan performa custom. Setiap rilis di-bangun dan diuji di device fisik, bukan emulator.

Selain kernel, aku ngembangin aplikasi Android dengan Kotlin + Jetpack Compose — UI liquid glass, Material 3, Room, dan detail micro-interaction. Standar visual-ku: kaca buram, transisi spring, angka yang berdetik halus.

Semua proyek live di GitHub sebagai source publik — build bisa dicek ulang, commit per commit.
